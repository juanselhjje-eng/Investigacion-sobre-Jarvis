# YouTube, Instagram y demostraciones públicas: método y primeros hallazgos

Fecha de consulta: 29 de octubre de 2026. Esta página registra una primera búsqueda, no una revisión exhaustiva de cada video o publicación.

## Qué debe analizarse en cada video

Para cada serie o demostración:
1. Identificar canal, título, fecha, URL y versión del código.
2. Separar introducción promocional, demostración real, tutorial de instalación, explicación de arquitectura y preguntas del público.
3. Registrar cada capacidad mostrada y si se ve el resultado completo.
4. Revisar descripción, repositorio enlazado, capítulos y comentarios accesibles.
5. Buscar videos de seguimiento y comparar si las funciones siguen disponibles.
6. Marcar como no verificado cualquier comportamiento que dependa de código no publicado, datos ocultos o edición de video.

## Redes sociales: cómo documentarlas

Instagram y otras redes pueden mostrar resultados incompletos si una publicación exige iniciar sesión, es privada, fue eliminada o está limitada por región. No se afirmará haber revisado comentarios que no estén visibles. Para cada publicación accesible, guardar URL pública, autor/canal, fecha, resumen, tema, número de respuestas visible solo si aparece y estado de acceso.

Categorías de publicaciones:
- Demo de una función nueva.
- Tutorial de instalación.
- Registro de errores.
- Petición de una función.
- Respuesta del creador o mantenedor.
- Comparación con otro proyecto.
- Corrección o retirada de una afirmación anterior.

## Preguntas que debe responder el análisis de comentarios

- ¿Qué preguntas aparecen repetidamente sobre instalación, API keys, coste, memoria y voz?
- ¿Qué errores informan los usuarios y qué datos técnicos incluyen?
- ¿El creador responde y la solución se confirma?
- ¿Se pide soporte para Windows, macOS, Linux, Android o iOS?
- ¿La audiencia pide más autonomía, privacidad, proveedores, conectores o memoria?
- ¿La función se implementa en una versión posterior?
- ¿Los comentarios confunden una demo con un producto terminado?

## Límites

No se puede medir la opinión de toda la comunidad con una muestra pequeña de comentarios. Los likes y vistas no prueban la calidad técnica. Los comentarios pueden ser incompletos, duplicados o poco específicos. La investigación debe mostrar ejemplos y enlaces, no inventar una encuesta global.
